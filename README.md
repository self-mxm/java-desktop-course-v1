# Cours Java pour débutants

Parcours progressif pour apprendre Java en construisant des applications. Aucun prérequis de programmation. Java 17 ou supérieur est recommandé.

## Chapitres

- [Chapitre 1 — Les fondamentaux de Java](chapitre-01-fondamentaux-java/README.md)

Pour suivre le cours, lisez les leçons dans l’ordre, exécutez les exemples, puis faites les exercices avant de consulter l’auto-évaluation. Pour compiler un fichier : `javac Nom.java`, puis `java Nom`.
